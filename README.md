# 폰 타자 연습

휴대폰 자판이 서툰 분(특히 중장년층)이 평소 쓰는 폰 자판 그대로, 실생활 카톡 문장으로 타자를 익히는 웹앱입니다.

## 바로 해보기
https://rorua-writer.github.io/phone-typing/

## 주요 기능
- 문자 연습: 상황별 카톡 문장
- 짧은 글, 속담·명언·성경(개역한글판) 연습
- 기호 연습: 삼성 키보드·아이폰 자판별 기호 위치 안내
- 자리 연습: 쿼티 / 천지인, 한 손가락 모드 기본
- 낱말 퀴즈
- 듣고 받아쓰기, 문장 부호 끄기

## 파일
- `index.html`: 앱 전체 (한 파일)
- `기획정리.md`: 기획과 진행 상황
- `CHANGELOG.md`: 바뀐 내용 기록

기록은 사용자 폰 안에만 저장되며 개인정보를 받지 않습니다.
